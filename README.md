# 鉄拳8 戦績カウンター (Tekken 8 Stats Counter)

『鉄拳8』のランクマッチやプレマのお供に。
配信画面の横やゲーム画面の裏にコンパクトに配置し、試合の合間に対戦結果や相手キャラへの対策メモを記録・確認できる専用の戦績管理ツールです。

---

## 🎮 主な機能と使い方（プレイヤー向けマニュアル）

### 1. マイキャラの設定

- 画面上部で自分の使用キャラクターを選択できます。

### 2. 直感的なキャラクター選択（ドラッグスクロール）

- 対戦相手のキャラクター一覧（シーズン3で実装予定のキャラを含める全44キャラ）は、**マウスのドラッグ操作（スマホでは画面のフリック操作）**で上下にスクロール可能です。

### 3. 戦績のクイック記録

- 相手キャラクターをクリックして選択後、そのキャラに対する「WIN（勝ち）」「LOSE（負け）」をワンクリックでカウントできます。
- 下部には直近の対戦履歴がリアルタイムでタイムライン表示されます。

### 4. キャラクター別の「対策メモ」

- トータル戦績の下部には、常にオープンな対策メモ入力欄が配置されています。
- キャラクターを一覧からクリックすると、そのキャラクター専用のメモ内容へと瞬時に表示が切り替わり、書き換えた内容は自動で保存されます。

---

## 📱 スマホ・タブレットでアプリとして使う

中身が完全にWeb標準（HTML/CSS/JS）で構築されているため、スマートフォンでも動作します。

1. 発行されたGitHub PagesのURLにスマホのブラウザ（SafariやChrome）でアクセスします。
2. ブラウザのメニューから **「ホーム画面に追加」** を実行します。
3. ホーム画面に誕生したアイコンをタップすれば、全画面のネイティブアプリのような佇まいで、自分だけの戦績データ（端末内の `localStorage` に安全に保存されます）を蓄積していくことができます。
